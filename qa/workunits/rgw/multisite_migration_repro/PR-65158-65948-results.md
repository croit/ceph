Raw leftover counts are timing/state dependent. Their change is not evidence of
a new regression by itself. No direct RADOS deletion was performed. The live
seed's empty OLH head is excluded from the three deleted-key-head finding.

### Plain deletion

Before: source null data disappeared, but Zone2 retained the original readable
payloads and numbered markers. After: both sites contain the same three null
delete markers and no null data versions. This validates the suspension-state
fix for the tested incremental-replication path.

### Explicit deletion is still a separate defect

After explicit single and bulk version deletion, Zone2 still reports “caught up”
while all three null payloads remain readable and byte-equal to the originals.
This is not merely a stale object count. PR #58133 and complete null-discriminator
propagation remain candidates; neither was applied in this retest.

### Copy and rename

After #65158, the replacement is readable before rename, after rename, and after
the OLD bucket is purged. Contents match expected hashes in both zones. The
earlier dependency on copied OLD OLH bookkeeping is absent in these fixtures.

### Rename synchronization

The checkpointed OLD bucket's version lists already matched before manual sync
and still matched afterward. Status temporarily reported seven shards behind;
manual sync returned 0 and status then reported caught up. This does **not**
reproduce the customer's persistent behind status or prove these PRs fix rename
identity/queued-work hazards. The backlog experiment was not part of this run.

## Conclusion

The two high-confidence candidates are now validated for their specific lab
failures: suspended plain DELETE replication and copy/rename readability.
They are **not a complete production-migration/cleanup fix**.

Next targeted work: null-version unlink propagation, then pending-OLH cleanup.
Do not infer that an upgrade heals pre-existing malformed copies or replica
surplus. Both patched clusters remain running, with current fixtures and logs
retained. Historical reports remain available, but fresh-cluster reset removed
the old baseline fixtures.
